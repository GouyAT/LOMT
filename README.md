> The Contact Sheet —— **合成体**：P3 的暗房视觉 + P4 的信息架构 + P1 的控件克制度。

## 一、为什么有第五代（问题与解法）

`../prototype-comparison.md` 的实测数据指出 P3/P4 的同一个病：

| | P3 | P4 | **P5** |
|---|---|---|---|
| 面板数 | 24 | 22 | **24（不减）** |
| 通向面板的常驻通道 | 2 | 5 | **1** |
| PC 首屏 chrome 控件 | 70—72 | 54—57 | **15（最坏 19）** |
| 移动端首屏 chrome 控件 | 34 | 28 | **8（最坏 11）** |
| 移动端 `<44px` 触控目标 | 22 | 23 | **0** |
| 导航类控件占首屏比 | 68% | 51% | **≈13%（2/15）** |

病根不是"功能做多了"，是**把功能清单直接翻译成入口矩阵**。
P5 砍的是入口：侧栏没有图标轨道、右墙没有速取矩阵、输入区没有常驻指令行、底部没有常驻底片条。

## 二、核心装置：接触印相样张

P3 把 24 个面板做成常驻底片条钉在屏幕底部——那等于把索引**永久展开**。
但暗房里本来就有个专门装置来干这件事：

> **接触印相样张**——把整卷底片压在相纸上曝一次光，得到一张缩略图，用来挑**哪一格值得放进放大机**。

| 交互 | 暗房动作 |
|---|---|
| 调出面板索引 | 取来样张（`` ` `` / `Ctrl+K` / 顶梁「样张」钮 / 移动端底部一格） |
| 浏览 24 面板 | 一张相纸上 6×4 格，三段染底色（红=叙事 / 蓝=玩法 / 灰=系统） |
| 打开面板 | 把那一格**架进放大机**，投影落到相纸上（先过曝再收敛） |
| 已打开 | 样张上那格转成**定影琥珀**边框 |
| 收起 | 收回**工作台底片夹** |

比星座启动器更好的三点：**天然网格**（不必设计 24 个坐标）、**自带分段**（染底色即分区，不需额外图例控件）、
**动作即隐喻**（"挑一格去放大"就是"打开一个面板"）。

## 五、设计系统（承袭 P3，令牌值不改）

```
暗室 60%   --void #100c0d  --room-1 #171113  --room-2 #211719  --room-3 #2c2022
相纸 30%   --paper #f1eade --paper-2 #e0d6c4 --ink #23201c     --ink-2 #514a41
银盐       --silver #c4ccd1 --silver-2 #8f989e --silver-4 #3d4448
强调 10%   --safelight #d2452e（安全灯红：氛围与危险）
           --cyan #2a6d90    （蓝晒蓝：信息与结构）
           --fixer #c9913c   （定影琥珀：收益，克制）
```

**纪律：红管氛围与危险，蓝管信息与结构，银管金属与分隔——三者永不在同一元素上混用。**

字体四角色：**Bodoni Moda**（Didone 铭牌 / 英文题头）· **Noto Serif SC**（中文正文与标题）·
**Courier Prime**（编号 / 坐标 / token / JSON）· **楷体**（相纸背面手写批注，极克制）。

P5 新增令牌只有布局：`--tap-min: 44px`（移动端触控地板）、`--bench-h`、`--z-contact`、`--z-shutter`。
**没有 `--rail-w`** —— 因为没有侧栏图标轨道。

## 六、Diegetic：界面即设定

P5 把 Diegetic 推进一层——**界面不只是"像"暗房，故事就发生在暗房里**。

- **主角**：以利亚·凡恩，24 岁，《廷根晚报》见习记者**兼暗房技工**
- **途径**：观众途径 · 序列 9「观众」；晋升体系扮演法「一名沉默的观众」
- **时空**：第五纪 1349 年 9 月 15 日 星期六 01:12 · 廷根市铁十字街 27 号地下一层
- **第七回合**：他在报社地下暗房冲洗昨夜在翡翠剧院拍的干版。第三块板子上有两个影子——
  一个是立镜前的他，另一个站在他身后半步，穿第三幕的斗篷，**脸的位置是一片过曝的白**。
  而他身后当时没有人。
- **可玩分支**：四条完整续写文稿（等字显完 / 开门 / 上楼 / 空座），互相交叉可循环，
  走完给出**诚实的 diegetic 收束**而非占位符

| 界面元素 | 暗房实物 |
|---|---|
| 六维属性 | **显影量筒**（玻璃管 + 药液 + 弯月液面 + 刻度 + 高光扫过） |
| 正文 | **相纸**（银盐逐字显影 + 显影不均 + 定影泛黄边） |
| 行动选项 | **晒片绳上的相片**（木夹 + 悬停摆动） |
| 面板索引 | **接触印相样张** |
| 面板 | **放大机投影** |
| 通知 | **相纸小样** |
| 确认框 | **显影计时器**（倒数转盘） |
| 警告 | **漏光**（环境级反馈） |
| 探索热区 | **放大镜圈** |
| 污染 / 失控 | **过曝** |
| 角色头像 | **玻璃干版肖像**（划痕 + 反光扫过） |
| 顶梁四灯 / 曝光计 / 安全灯 | **只读指示物，一个控件都不占** |

## 七、控件预算（P5 的第一性约束）

### PC 首屏常驻 chrome：19 个（上限 22）

暗房横梁 4（样张 / 端切换 ×2 / 皮肤）· 三态循环钮 1 · 晒片绳相片 4 ·
输入区 4（输入 / 快门 / 回退 / 回合菜单）· 左脊标 1 · 相片墙 5（脊标 / 头条 / 在场 ×3）· 工作台 **0**

### 移动端首屏常驻 chrome：11 个（上限 12）

切回桌面端 1 · 三态循环 1 · 晒片绳相片 4 · 输入 1 · 快门 1 · 底部三标签 3
（移动端额外减法：样张钮走底部标签、皮肤钮走设置面板、当前端形态钮冗余移除、回退并入回合菜单）

### 相对 P3/P4 砍掉的东西

1. 侧栏图标轨道（P4 左 6 + 右 9）→ 删；侧栏只放内容
2. 卷宗速取矩阵（P4 8 张卡）→ 删；速取就是样张
3. 常驻指令 chip 行（P4 9 个）→ 输入框内 `/` 自动完成
4. 三态三个钮 → 1 个循环钮（快捷键保留）
5. 回合操作 5 钮 → 1 个回合菜单
6. 左栏 4 个折叠头 → 全改只读读数区
7. 常驻 24 格底片条（P3）→ 按需调出的样张
8. 工作台不重复列出已打开窗口 → 只列已收回的

### 闸门（防止减完再长回来）

`checks.mjs` 内置**控件预算断言**：PC ≤22 · 移动端 ≤12 · `<44px` 触控目标 =0 · 面板通道 =1，
并额外测**最坏情形**（相纸滚到底、4 张行动相片同时可见）。超预算即 FAIL。

## 九、已知边界

- **无后端**：涉及模型调用、生图、云端的按钮给出**诚实的界面反馈**，不假装成功，也不弹浏览器错误框。
- **背景图为远程 URL**：离线时显示程序化暗房雾街场景（本机截图即此形态）。
- 验收截图使用系统回退字体；联网时自动切换 Bodoni Moda / Noto Serif SC / Courier Prime。
- 移动端不启用多窗口，面板改为全屏相纸；三态在移动端同样可用。
- **面板内组件自 P4 移植**（令牌与类名已整体映射到 P3 暗房体系），因此面板内部的信息架构沿用 P4 的成熟结构。

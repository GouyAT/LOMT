# 诡秘剧场 · 前端原型 3「灵异显影室」

《诡秘之主》AIRP 重制版 —— **前端原型 3**（纯前端、零后端、零构建、零依赖）。

> 前两代把界面做成了「剧院」和「机器」；这一代把界面做成**一间暗房**——
> 你不是在读文本，你在**显影**灵界留下的影像与记录。

## 运行（零门槛）

```
双击 index.html 即可运行（file:// 兼容，经典 script，无构建、无 npm install）

node checks.mjs        # DOM 级自动化验收（147 项）
node shots.mjs         # 生成 36 张验收截图到 screenshots/
node tools/audit.mjs   # 设计审计：WCAG 对比度 / 控件遮挡 / 字体落地 / 触控尺寸
```

> 沙箱说明：checks / shots / audit 需启动 headless chromium 子进程（`--remote-debugging-pipe` 命名管道），
> 本机受限沙箱下须以更宽权限运行；普通用户机器直接 `node checks.mjs` 即可（依赖 `../p1-demo/node_modules/playwright`）。
> 场景图引用老卡 `i.postimg.cc` 背景图，加载失败自动回退程序化暗房场景；
> 字体经 Google Fonts CDN（Noto Serif SC / Bodoni Moda / Courier Prime），断网回退系统衬线。

| 维度 | 原型1 诡秘剧场 | 原型2 灵界电讯差分机 | **原型3 灵异显影室** |
|---|---|---|---|
| Diegetic 隐喻 | 剧院舞台 · 帷幕 | 黄铜差分机 · 电报 | **暗房 · 灵异摄影 · 幻灯机** |
| 主色骨架 | 深渊黑 + 烛金 + 天鹅绒红 | 煤烟绿黑 + 黄铜 + 铜绿 | **安全灯红 + 蓝晒蓝 + 银盐灰** |

| 警示通道 | 红色描边 | 铜锈红阀 | **安全灯抖动 + 全屋漏光**（环境级反馈，不弹红框） |
| 主题皮肤 | — | 3 套（差分机 / 剧本 / 暗夜） | **3 套（显影室 / 蓝晒工房 / 银版镜庭）** |

**结论**：三代之间不是换皮，是换世界。P3 的每个交互都能回答「它在暗房里是什么」。

### 为什么「灵异摄影」是诡秘题材的最优隐喻

1. **史实对位**：湿版摄影（1851）、蓝晒法（1842）、幻灯放映都是维多利亚时代的黑科技；
   而**灵异摄影本身就是维多利亚降灵会热潮的核心道具**——"相机能拍到肉眼看不见的东西"。
2. **世界观对位**：灵界 / 显形 / 幻觉 / 窥视 ⇄ 显影 / 定影 / 过曝 / 底片反转。
   序列越高看得越多 = **感光度越高**；污染 = **相纸灰雾（fog）**；失控 = **过曝**。
3. **交互红利**：显影自带时间轴（承载流式输出）；幻灯机自带空间轴（承载模态入场）。

## 三、设计系统

### 色板（60-30-10：暗室 60 / 相纸银 30 / 安全灯+蓝晒 10）

```
暗室   --void #100c0d   --room-1 #171113  --room-2 #211719  --room-3 #2c2022
相纸   --paper #f1eade  --paper-2 #e0d6c4 --ink #23201c     --ink-2 #514a41
银盐   --silver #c4ccd1 --silver-2 #8f989e --silver-3 #5d666b
强调   --safelight #d2452e（安全灯红：氛围与危险）
       --cyan #2a6d90    （蓝晒蓝：信息与结构）
       --fixer #c9913c   （定影琥珀：收益，克制）
```

**红管氛围与危险，蓝管信息与结构，银管金属与分隔**——三者永不在同一元素上混用。

### 字体角色（4 角色，与 P1/P2 全不重叠）

| 角色 | 字体 | 用途 |
|---|---|---|
| Display 西文 | **Bodoni Moda**（Didone 高反差） | 铭牌、面板英文题头、大写小标 |
| 正文/标题中文 | **Noto Serif SC** 400/500/700/900 | 叙事正文、标题（字距放宽） |
| 技术/编号 | **Courier Prime**（打字机等宽） | 编号、坐标、token、日志、JSON |
| 批注 | **LXGW WenKai / 楷体** | 相纸背面手写批注、图注（极克制） |

### Signature 元素（只在这几处大胆，其余安静）

1. **显影式正文** — 逐段从 `blur(7px) + 低反差 + 下沉` 收敛到锐利
2. **幻灯机投影面板** — 光锥射出 + `rotateY` 梯形落定 + 光束浮尘 + 暗角
3. **底片条导航** — 悬停那一格从背面被灯箱点亮
4. **蓝晒图舆图** — 全站唯一一次强烈色彩事件
5. **晾片绳选项** — 夹子 + 摆动 + 脱夹落下
6. **安全灯即警示通道** — 危险时整间暗房的光会抖

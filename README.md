# 诡秘剧场 · 前端原型 4「汞镜案台」

> The Mercury Docket —— 《诡秘之主》AIRP 重制版 **前端原型 4**（纯前端 / 零后端 / 零构建 / 零依赖）。
> 与原型 1（深渊黑 + 烛金 + 天鹅绒剧院）、原型 2（煤烟绿黑 + 黄铜 + 铜绿差分机）刻意差异化：
> **石板靛 + 冷银白镴 + 普鲁士蓝 + 紫水晶**，Diegetic 概念 = 灰雾之上的**星象案台**。
>
> 一句话设计主张：**界面是冷的银器，故事是暖的灯火。**

---

## 运行

```
双击 index.html                  # 零构建、零依赖、file:// 直开
node checks.mjs                  # DOM 级自动化验收（103 项）
node audit.mjs                   # 客观视觉审计（对比度 / 裁切 / 重叠 / 星座间距 / 调色板）
node shots.mjs                   # 生成验收截图到 screenshots/（40 张）
```

> `checks.mjs` / `audit.mjs` / `shots.mjs` 复用 `../p1-demo/node_modules/playwright`。
> 本机沙箱下启动 headless chromium 需更宽权限（命名管道），普通机器直接 `node checks.mjs` 即可。
> 场景图引用旧卡 `i.postimg.cc` 素材，加载失败自动回退**程序化 SVG 雾街场景**（截图即此形态）；
> 字体经 Google Fonts CDN（Cormorant Garamond / Noto Serif SC / Noto Sans SC / IBM Plex Mono），断网回退系统衬线。

## 演示剧本（真实内容，零占位符）

- **主角**：以利亚·凡恩（Elijah Vane），24 岁，《廷根晚报》见习记者
- **途径**：**观众途径 · 序列 9「观众」**——读心，与「诡秘剧场」母题共振；晋升体系为扮演法「一名沉默的观众」
- **时空**：第五纪 1349 年 9 月 14 日 星期五 21:47 · 鲁恩王国 · 廷根市 · 铁十字街 · 翡翠剧院后台走廊
- **钩子**：他为追查「翡翠剧院连环失踪案」混入后台。三名失踪者共用一个十九年未售出的座位 F-13；
  《灰雾之上》第三幕缺页；后台地板有与其父遗物同源的银灰色粉末；道具间的立镜里，有人正用缺页上的台词低语。
- **在场**：舞台监督 玛戈·希尔（隐瞒）／女主角 塞西莉亚·朗（恐惧）／后台杂役 老图恩（醉意）
- **可玩分支**：四条完整续写文稿（旁听 / 台词 / 扫帚 / 空座），互相交叉可循环，走完后给出**诚实的 diegetic 收束**而非占位符

所有面板数据彼此引用：报纸头条提及失踪案 → 案卷线索指向替补名单 → 图鉴收录塞西莉亚 →
伏笔台账登记镜后低语 → 编年史大总结复述全部 → 世界书条目为这些内容提供注入规则。

## 已知边界

- **无后端**：涉及模型调用、生图、云存档的按钮给出**诚实的界面反馈**（如显影室 3 秒后返回「未配置绘图后端」），
  不假装成功，也不弹浏览器错误框。
- **背景图为远程 URL**：离线/受限网络下显示程序化 SVG 雾街场景（本机截图即此形态）。
- **验收截图使用系统回退字体**；联网时自动切换 Cormorant Garamond / Noto Serif SC。
- 移动端不启用多窗口，面板改为全屏 sheet；三态中「探索」态在移动端同样可用（点击缩略纸角回到叙事）。
